# tp-reel-tdah-ihm
Repositorio utilizado para subir los entregables del Trabajo práctico de Interfaz Hombre-Máquina

# TP - Reel sobre TDAH 

## Tema
Generación de un video breve que explique por qué un diseño claro ayuda a captar la atención de usuarios con TDAH.

## Idea principal
Menos ruido visual, más atención.

## Descripción
El proyecto consiste en un reel animado protagonizado por mi gato, que representa el paso desde la saturación visual hacia un estado de calma y atención. El video utiliza una narrativa simple basada en cuatro escenas: ruido visual, pausa/contención, reducción de estímulos y calma final.

## Herramientas utilizadas
- ChatGPT: análisis del contenido, generación de ideas, hooks, storyboard y prompts.
- ChatGPT Images: generación de imágenes base.
- Meta IA: animación de escenas.
- CapCut: edición final, textos, música lofi y efectos de sonido.

## Estructura del video
1. ¿Demasiado ruido visual?
2. Una pausa también ayuda.
3. Menos estímulos, más calma.
4. Menos ruido visual, más atención.

## Archivos incluidos
- Informe final en PDF.
- Texto PDF utilzado como referencia para la extraccion de contenido.
- Video final en formato MP4.
- Prompts utilizados para generar imágenes y animaciones.
- Storyboard del video.
